## 🗺 學習路徑建議

依課程難度可分為三個階段：

### 1. 🟢 入門

課程 1～2，建立 Power BI Desktop 與 Power Query 的基本操作能力。

```mermaid
flowchart LR
    C1["10 PBD介面操作與PQ資料匯入"] --> C2["11 PQ資料前處理與巨量資料"]
```

### 2. 🟡 初階

課程 3～6、9～10，學習資料型別、星狀結構建模、視覺效果與 DAX 基礎量值。

```mermaid
flowchart LR
    C3["30 資料型別、分析顆粒度"] --> C4["31 資料建模、事實表與維度表"]
    C4 --> C5["70 視覺效果、常見圖表"]
    C5 --> C6["50 用DAX創建量值和資料行"]
    C6 --> C9["53 DAX排版、型別計算、空值空白"]
    C9 --> C10["54 DAX日期格式化、日期表"]
```

### 3. 🔴 進階

課程 7～8、11～12，深入 DAX 評估上下文、彙總函數與時間智慧函數的應用。

```mermaid
flowchart LR
    C7["51 DAX評估上下文運作原理"] --> C8["52 DAX彙總函數"]
    C8 --> C11["55 DAX同期比、前期比"]
    C11 --> C12["56 DAX移動線、期末結餘"]
```

> 建議依 No. 順序來安排 BI 資料建模的學習，前面初階課程的概念會是後續進階 DAX 課程的先備知識。
