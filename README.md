# BI Design 專案目錄

本目錄收錄各 Power BI 報表的設計文件，適合初次接觸或想快速掌握 BI 建模的初學者，透過實際專案的設計思路與排錯經驗，了解各種做法的適用情境。

---

## 專案列表

### 案例 1. [家庭共帳 Power BI 報表](README_finance.md)

| 項目 | 說明 |
|------|------|
| 成果檔案 | `family_finance.pbix` |
| 設計概念 | 「分類維度 + 明細事實」的雙層 ETL 架構，大/中分類採會計科目式層級編碼（A01、B02…） |
| 資料流 | Power Query 負責讀取與轉型原始 Excel；DAX 在模型層產生日期、年月、個帳等計算維度表 |
| 可能用途 | 家庭記帳追蹤、個人收支分析；架構可能移植至製造業成本報表（料/工/費的科目替換即可） |
| 擴充方式 | 新年度只需在 `fact_accounts\` 放入新 Excel，報表自動合併 |

### 案例 2. [銷售實績 Power BI 報表](README_sales.md)

| 項目 | 說明 |
|------|------|
| 成果檔案 | `v3.1_full.pbix`、`v3.1_finance.pbix` |
| 設計概念 | SQL 端源頭篩選 (查詢下推) 取代 Power Query 端全量篩選，並依不同部門需求切分欄位範圍 |
| 資料流 | PostgreSQL Direct Query 串接財務系統的 table，同時根據年月、公司別參數組成 WHERE 子句下推至資料庫 |
| 可能用途 | 財務會計跨部門報表；解決舊版全表撈取導致的逾時與效能問題 |
| 擴充方式 | 依 `v{主版號}.{次版號}_{欄位模式}.pbix` 命名規則建立新分支版本，並於共用 CHANGELOG 記錄異動 |
